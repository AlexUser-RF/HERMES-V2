# MSYS quirks — evidence log (captured 2026-08-09, Windows 10 host, git-bash)

Each entry: what was attempted, the exact failure, the working alternative.

## 1. Native git cannot take `/c/...` paths in `-C`

Attempted (inside a bash script generated by a third-party installer):

```bash
git -C "$INSTALL_DIR" pull --ff-only   # INSTALL_DIR=/c/Users/Administrator/hermes-workspace
# fatal: cannot change to '/c/Users/Administrator/hermes-workspace': No such file or directory
```

Working:

```bash
INSTALL_DIR="C:/Users/Administrator/hermes-workspace" bash install.sh
# "Already up to date." — forward-slash Windows path accepted by both bash and git
```

Lesson: when a bash script shells out to native git with a path derived from `$HOME`
(which is `/c/Users/...` under MSYS), override the path variable with a `C:/...`-style
value at invocation.

## 2. curl cannot write to MSYS `/tmp`

```bash
timeout 20 curl -fsSL "https://host/install.sh" -o /tmp/hw-install.sh
# curl: (23) client returned ERROR on write of 3060 bytes
```

Working: write into the current working directory (`-o "$(pwd)/install.sh"` or `cd` to a
real dir first). MSYS `/tmp` is a virtual mount native curl can't resolve for output.

## 3. Killing processes: taskkill flag mangling

Attempted:

```bash
taskkill //F //PID 18020        # Ошибка: неверный параметр - '//F' (invalid argument)
cmd //c "taskkill /F /PID 18020"  # dropped into interactive cmd prompt instead of executing
```

Working:

```bash
powershell -Command "Stop-Process -Id 18020 -Force"
```

Note: killing the `pnpm dev` parent (via Hermes `process kill`) left the child vite/node
holding port 3000 — always re-check `netstat -ano | grep LISTEN` and kill the child PID.

## 4. Exit status through a pipe

```bash
timeout 30 git ls-remote https://github.com/X/Y.git 2>&1 | head -5; echo "EXIT=$?"   # always 0
```

`$?` is the exit of `head`, not git. Use `PIPESTATUS[0]`:

```bash
... | head -5; echo "EXIT=${PIPESTATUS[0]}"
```

This also masked a real installer failure earlier in the session — the script had died on
`git pull` but `bash install.sh 2>&1 | tail -40` reported exit 0.

## 5. Private repo detection

- `git ls-remote` on a private repo with no creds hangs (waiting at terminal prompt).
  Fix: `export GIT_TERMINAL_PROMPT=0; timeout 40 git ls-remote ...`
- Anonymous GitHub API returns `404 Not Found` for private repos — same body as a
  non-existent repo. Only a token-authenticated request distinguishes them:

```bash
curl -s -H "Authorization: token ghp_..." https://api.github.com/repos/OWNER/REPO
```

## 6. CRLF warnings in git on Windows

On the first backup commit git printed `warning: LF will be replaced by CRLF` per text
file. Fix: repo-root `.gitattributes` containing `* -text`, committed once. After that
`git add -A` is silent.

## 7. Broken corepack/pnpm shims

`pnpm -v` errored: `Cannot find module 'D:\c\Users\Administrator\...\corepack\dist\pnpm.js'`
(notice the mangled `D:\c\...` prefix). The `pnpm` on PATH was a shim pointing at a broken
corepack. Fix: `npm install -g pnpm --force` → `pnpm -v` returned 11.21.0.

## 8. taskkill warning about stray listener

After `hermes dashboard` / `pnpm dev` were killed through the process manager, the UI port
(3000) was still held by the vite child (PID 18020). `netstat -ano` + `Stop-Process` used
to clean up. TIME_WAIT entries afterwards are harmless.
