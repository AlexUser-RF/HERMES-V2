# Сбор аналогов недвижимости с Авито (m.avito.ru)

## Когда использовать
Нужно собрать реальные объявления-аналоги для оценки стоимости квартиры/объекта (флиппинг, анализ рынка). Desktop-сайт avito.ru, cian.ru, yandex, google — режут по IP/капчей. Мобильная версия **m.avito.ru** отдаёт полные структурированные данные без антибот-блока.

## Как это работает
Страница m.avito.ru содержит `window.__initialData__` — JSON-строку с карточками объявлений (цена, площадь, этаж, район, адрес, признак новостройки/вторички). Данные зашиты в HTML, обычный `curl` их получает.

## Шаги

### 1. Скачать страницу (curl с мобильным UA)
```bash
UA="Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/17.0 Mobile/15E148 Safari/604.1"
curl -s -m 20 -L -A "$UA" "https://m.avito.ru/tula/kvartiry/prodam/vtorichka/2-komnatnye" -o page.html
```
URL-структура: `m.avito.ru/<город>/kvartiry/prodam/<vtorichka|novostroyka>/<N-komnatnye>`
- `vtorichka` — вторичка (отфильтрует новостройки)
- `2-komnatnye`, `1-komnatnye` и т.д.
- Пагинация: добавить `?p=2`, `?p=3`...

**ВАЖНО про пути на Windows:** нативный curl не понимает MSYS-пути `/tmp/...`. Сохранять в реальную папку с буквой диска, напр. `D:/path/page.html`.

### 2. Извлечь и распарсить `__initialData__`
Данные закодированы в ДВА слоя JSON-экранирования. Распарсить:
```python
import re, json
raw = open(path, encoding='utf-8', errors='ignore').read()
m = re.search(r'window\.__initialData__\s*=\s*"(.*?)";', raw, re.DOTALL)
data = json.loads(json.loads('"' + m.group(1) + '"'))
items = data['search']['allItems']  # dict {item_id: card}
count = data['search'].get('count')  # всего объявлений
```

### 3. Поля карточки
Каждая карточка `items[id]['value']`:
- `freeForm` — сложная структура с текстовыми полями по `id`:
  - `titleLabelRich` — "2-к. квартира, 43,2 м², 5/5 эт."
  - `highlightedPriceLabelRich` — полная цена "3 900 000 ₽"
  - `normalizedPriceLabelRich` — цена за м²
  - `geoReferenceLeftLabel` — район ("р-н Советский")
  - `descriptionLabelRich` — описание
  - `developmentViewLink` — адрес (часто содержит адрес, напр. "ул. Фрунзе, 17")
- `price.current` — цена
- `uri` — ссылка на объект

Извлечение текста по id (freeForm — список диктов):
```python
def get_text(ff, key):
    s = json.dumps(ff, ensure_ascii=False)
    m2 = re.search('"id": "%s".*?"(?:title|text)": "([^"]*)' % key, s)
    return m2.group(1).replace('\\xa0',' ').strip() if m2 else None
```

### 4. Фильтрация и анализ
- Район: поле `district` / `geoReferenceLeftLabel`
- Вторичка/новостройка: `uri` содержит `novostroyka` → новостройка, отфильтровать для вторички
- Площадь: распарсить из title
- Собрать сводку: медиана/средняя ₽/м² по району и диапазону площадей
- Сравнить с целевой ценой объекта → вывод о достижимости цены продажи

### 5. Генерация кликабельных ссылок на объявления (ВАЖНО)
Каждое объявление имеет `uri` вида `/tula/kvartiry/2-k._kvartira_448_m_55_et._7207378935?context=...`. Чистая рабочая ссылка для пользователя:
```python
def avito_link(uri):
    path = re.match(r'^([^?]+)', uri or '').group(1)
    return "https://www.avito.ru" + path
```
```
https://www.avito.ru/tula/kvartiry/2-k._kvartira_448_m_55_et._7207378935
```
**Зачем:** цена аналога сильно зависит от РЕМОНТА/состояния, а не только от района. Две квартиры на одной улице могут отличаться на 200–500к и даже в 2 раза только из-за состояния (пример: Смидович 8 → 83к/м² vs Смидович 4 → 170к/м²). Поэтому всегда выдавай ссылки на ключевые аналоги — пользователь сам откроет и увидит фото/состояние ремонта.

**Важно про открытие ссылок:** сам агент через curl не откроет (антибот, HTTP 439/«проверка безопасности»), но для пользователя ссылка валидна — он открывает в своём браузере с локальным российским IP. Всё равно всегда включай ссылки в выдачу.

Для выдачи по «тяжёлым» сопоставимым (топ-этаж 5/5, ~43–45 м²) — группировать как «прямые аналоги» и давать ссылки каждой.

## Питфоллы
- Пути `D:/...` (не `/tmp/`) на Windows-curl
- Двойное JSON-экранирование при парсинге
- Адрес часто в `developmentViewLink` (поле "адрес"), а не в `addr`/`addressLabel`
- Цена может быть в `highlightedPriceLabelRich` (полная) или только в `normalizedPriceLabelRich` (за м²) — брать оба
- Старые страницы могут содержать рекламные/инородные объявления — фильтровать по району и типу
- Добавлять паузу 0.5–0.6с между страницами, чтобы не словить троттлинг
- Cian (cat.php) тоже отдаёт данные, но они смешанные (разные города, реклама) — m.avito надёжнее
- Для ссылки отбрасывать `?context=...` из `uri` (длинный мусорный параметр)
- Пользователь открывает ссылки сам (у него локальный IP); агентский curl блокируется — это нормально

## Домклик (domclick.ru)
Закрыт жёсткой капчей `qrator` (отвечает HTTP 401 с `/__qrator/qauth...` скриптом) — через curl НЕ парсится. Их объявления вторички в основном дублируются на Авито, так что m.avito покрывает задачу. Если нужен именно Домклик — отдельный путь (браузер или ручная выдача), в стандартный метод не включён.

## Верификация
- Проверить `data['search'].get('count')` — реальное число объявлений
- Сверять собранные цены/адреса с объектом (например, найти сам объект в выдаче)
- Проверить, что сгенерированная ссылка содержит id из карточки и открывается у пользователя
