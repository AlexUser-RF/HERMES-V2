## ⚡ Инженерный стандарт «Каскад 10/10»

Главная цель — нулевой перерасход токенов, сохранение чистоты контекста и максимальная скорость.
1. **Уровень 0 (Системный срез):** Строго нативный CLI (`git`, процессы, ОС) с жестким лимитом вывода.
2. **Уровень 1 (1–3 файла):** Нативные файловые инструменты (`read_file`, `search_files`, `patch`).
3. **Уровень 2 (От 4 файлов, таблицы, сметы):** Локальные `.py` скрипты с прямым доступом к диску через `pathlib`/`csv`/`json`.
4. **Уровень 3 (Local Data Spill):** Сырые массивы пишутся в кэш/файлы; в контекст отдаются строго 1–3 строки итоговых цифр.
5. **Уровень 4 (execute_code):** Только при необходимости прямого доступа к API и toolset Hermes.
